2. Luồng control

Chọn từng hướng để xem thứ tự chính xác. Mỗi bước chỉ chạy sau khi bước trước thành công.

01
React gọi call(calleeId)

Hook khóa thao tác trùng, đặt state preparing và không để UI tự gọi RPC sai thứ tự.

02
Browser → gateway: call-outgoing-preflight

Gateway kiểm tra Zalo online rồi gọi /api/voicecall/requestcall để lấy call ID, session và relay candidates.

03
Gateway đăng ký caller relay

Backend đọc rtpaddr/rtcpaddr, tạo Opus + SRTP context và thử từng candidate. Chưa có bước này thì không gửi lời mời.

04
Browser xin microphone và tạo WebRTC offer

getUserMedia() → RTCPeerConnection → ICE gathering hoàn tất. Đây là lúc trình duyệt cần quyền mic.

05
Browser → gateway: media-offer

Gateway tạo MediaSession, trả WebRTC answer và nối PCM từ browser vào relay bridge.

06
Browser → gateway: call-outgoing-invite

Backend dựng payload negotiated rồi gọi /api/voicecall/request. Lúc này bạn bè mới bắt đầu nhận chuông.

07
Zalo trả ringing / answer

Event control đi vào listener. Gateway ghép đúng call ID, đọc codec/extendData và chuẩn bị media theo answer.

08
Confirmed → mở audio hai chiều

Sau answer ACK khớp, state chuyển connected. Mic PCM mới được phép mã hóa và gửi sang relay.

Điểm dễ sai: gọi call-outgoing-invite trước media-offer, hoặc bỏ qua caller relay. Khi đó Zalo có thể nhận /request nhưng media không có đường đi và báo mạng lag.
01
Zalo listener nhận control request

Backend đọc offer thoại, giữ thông tin nhạy cảm trong server và gửi event đã rút gọn incoming-control cho React.

02
Gateway tự đăng ký incoming relay

Backend lấy relay endpoint từ offer, mở UDP socket, tạo Opus/SRTP context và giữ keepalive. UI chỉ thấy trạng thái đã sẵn sàng.

03
React hiển thị “Có cuộc gọi đến”

Chưa mở mic và chưa gửi answer chỉ vì đã thấy event. Người dùng phải bấm Nghe.

04
React gọi answer()

Hook thực hiện call-relay-connect (idempotent), xin quyền mic và tạo WebRTC offer.

05
Gateway xử lý media-offer

Backend tạo browser media bridge, trả WebRTC answer và nối PCM nhận từ browser với relay.

06
Gateway gửi call-accept

Backend gửi answer signaling tới Zalo. HTTP thành công chưa có nghĩa audio đã connected.

07
Chờ peer answer_ack

Chỉ khi call ID khớp và ACK đến, gateway chuyển confirmed=true và mở mic TX.

Lợi ích của thứ tự này: browser có thể hiển thị cuộc gọi đến trước, nhưng audio chỉ được mở sau khi relay, WebRTC và answer signaling đều đã chuẩn bị.

TX Browser → Zalo

Microphone → WebRTC → Node RTCAudioSink → mono PCM 48 kHz → Opus encode → RTP/SRTP protect → UDP relay.

RX Zalo → Browser

UDP relay → SRTP unprotect → Opus decode → PCM 48 kHz → Node RTCAudioSource → WebRTC → Web Audio speaker.

UI React control

React không cầm cookie, session ID, SRTP key hoặc relay token. Nó chỉ nhận state đã sanitize và gửi action qua WebSocket.

Đây là điểm backend nặng nhất: mỗi chiều phải chuyển đổi giữa WebRTC, PCM, Opus và RTP/SRTP. React render không phải bottleneck chính.

React gọi hangup()

UI chuyển sang ending, dừng WebRTC, dừng mic track và giải phóng AudioContext.

02

Backend chọn cancel hay endcall tùy phase, gửi signaling và đóng media/relay.

03
Zalo phát event terminal

cancel, endcall hoặc end_call làm sạch call state và relay còn lại.

04
UI trở về idle

React xóa incoming card, reset direction và chờ cuộc gọi mới.

3. State machine tổng quan

State ở frontend là biểu diễn UI; trạng thái media thật vẫn được xác nhận bởi gateway và event Zalo.

0 idle

Không có call, không giữ mic, không giữ relay.

1 preparing

Đang preflight, đăng ký relay hoặc tạo browser offer.

2 ringing

Outgoing đã gửi request hoặc incoming đang chờ người dùng.

3 connected

Media bridge sẵn sàng và peer ACK đã khớp.

4 ending

Đang dừng WebRTC, relay và gửi end/cancel.

! error

RPC, ICE, relay, codec, SRTP hoặc quyền mic thất bại.

5. Các gate làm cuộc gọi dừng

Nhìn vào gate cuối cùng đạt được sẽ biết lỗi nằm ở signaling, relay hay media.

Preflight status ≠ connected

requestcall trả status 0 và caller relay registered chỉ chứng minh relay đã mở. Chưa có chuông, chưa có /request và chưa có audio hai chiều.

Relay registered ≠ media ready

Relay socket có thể đã sống nhưng Opus/SRTP context, browser WebRTC hoặc SRTCP capability vẫn chưa khớp.

HTTP accept ≠ answer ACK

Backend chỉ mở microphone TX sau event ACK có call ID khớp. Điều này tránh gửi audio trước khi peer thực sự xác nhận.
